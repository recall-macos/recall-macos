Release Changelog

Discover new features, performance refinements, and software updates for Sapphire on macOS.

Latest Stable Release

3.0

September 15, 2026

NOTE: This is an early release and may have several bugs

Bug Fixes:

  • Fixed an issue where the weather persistent live activity wouldn't show
  • Fixed an issue where ghost windows would show on mac os 27
  • Fixed an issue regarding settings import
  • Fixed an issue where automation permission would never show as accepted
  • Fixed an issue where app list wouldn't load
  • Fixed an issue where safari wouldn't show in the app list
  • Fixed an issue regarding size of certain live activities
  • Fixed an issue regarding snap zones behaviour on multiple displays
  • Fixed an issue where media widget wouldn't hide although there's no music playing
  • Fixed an issue where notch could duplicate
  • Many other bug fixes

Improvements:

  • Improved multi monitor experience
  • Improved app performance (app now idles at 0% cpu usage)
  • Improved settings menu experience with categories
  • Improved Pill HUD
  • Added an option to hide airdrop within the file drop popup
  • You can now see all keyboard shortcuts in a dedicated menu
  • Added information on for which feature each permission is required
  • Improved performance of hover detection
  • Improved detection of snap zone drags
  • Improved detection of file drags
  • You can now adjust audio settings within the app
  • You can now turn off auto update
  • You can now turn off update live activity
  • Other performance improvements

New features:

  • Replaced liquid glass intensity with liquid glass style
  • Added menu bar profiles (requires subscription)
  • Added an option to have pill HUD on top
  • You can now configure the location you want face ID to be enabled in
  • Added tidal API (beta)
  • Added an option to add lyrics delay
  • Added a timer widget

Audio:

  • Introduces 8D audio (requires subscription)
  • Introduces surround sound (requires subscription)
  • You can now change the eq bands, up to 31 bands

Clipboard (new features requires subscription)

  • Introduces clipboard quick picker
  • Introduces auto-clear clipboard
  • Introduces finder cut & paste
  • Introduces text snippets

System enhancements:

  • Introduces app switcher; you can replace the native cmd + tab menu (requires subscription)
  • You can now quit an app when its last window has been closed
  • You can now add a close app and window shortcut protection
  • You can now change the green expand button to expand the app in the current space rather than bringing it to fullscreen

Snap Zones:

  • Introduces snap zones shortcuts; use a shortcut to bring the desired window to the desired portion of the screen
  • Introduces a new smooth resize option

Dock:

  • Introduces dock layouts; change to a desired dock layout and setting through a hotkey (requires subscription)
  • Introduces dock previews; preview any dock element by hovering over its app icon for bit (requires subscription)
  • Introduces dock behaviours; adjust whether you want dock settings to be display specific and also configure the dock to only show running apps
  • Customize what clicking the app icon for a dock app does

Media optimizer:

  • Automatically optimize the size of images on your clipboard (requires subscription)
  • Show file optimizer options within settings
  • Copy on screen text using a single shortcut (requires subscription)

Mouse:

  • You can now invert your mouse's vertical and horizontal scroll direction
  • You can now disable pointer acceleration
  • You can now configure specific mouse buttons
  • Added an option to focus the app where the cursor lies
  • Other mouse settings

Monitoring:

  • Added an option to show system stats in menubar (requires subscription)

Developers:

  • Added an option to show status of terminal, ai agents, builds, etc
  • Added an option to put device on caffeinate while dev activities mentioned above are running

Emojis:

  • Added an emoji picker
  • Added an option to suggest emojis as you type (requires subscription)

Archive & DMG:

  • Sapphire can now open archives of all types, detailed progress is shown in the notch or popup depending on user configuration
  • Sapphire can now open DMG files, place the app in the Application folder and automatically delete the DMG file (requires subscription)

Apps:

  • You can now scan for updates across your applications
  • You can now cleanly uninstall apps. Sapphire deletes the application and all files related to it

Storage (requires subscription):

  • Scan your entire disk, remove caches, large files, etc

Android Continuity (requires subscription):

  • Sync clipboard between your devices (does not require subscription)
  • Show phone notifications
  • Show phone live activities
  • Show media controls
  • Handoff apps and websites between your devices
  • Sync notification mode/dnd (does not require subscription)
  • Transfer files between your devices (does not require subscription)
  • View phone files in finder
  • Copy new photos to mac automatically
  • Mirror your mac's screen
  • Extend your mac's screen
  • Use your mac's keyboard and mouse on your android device
  • Remotely access and control your mac from your phone
  • Continuity camera
  • Continuity microphone
  • Scan documents for your mac with your phone
  • Play phone audio to mac (does not require subscription)
  • Automatically switch earbuds between your devices
  • Mirror your phone on your mac
  • Instant hotspot
  • Sync focus session and blocked apps between your devices

iPhone Continuity:

  • Transfer files between your devices
  • Sync focus session and blocked apps between your devices (requires subscription)

Known issues:

  • Issues regarding apple music remain
  • Liquid glass can be buggy
